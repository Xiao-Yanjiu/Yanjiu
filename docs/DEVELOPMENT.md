# 开发与发布约定

- 主仓库统一存放插件、Android App、完整对应源码及必要许可。
- 本地测试包、构建工具、密钥和备份保留在用户指定目录，不能提交到公共仓库。
- 独立插件迁移之前保留 `legacy/PhoneChat.cs`，不得把旧模块当成已完成的独立插件发布。
- 不把实时聊天事件或内容猜测补入规范窗口缓存；原生依日志编号和系统过滤，Omni依窗口自身记录与过滤结果。
- 数据和通知保持独立，聊天使用磁盘缓存和有界分页，禁止无上限内存列表。
- 设备授权、QQ登录票据和推送密钥加密保存；不降低TLS认证或公开匿名聊天接口。
- 修改后完成相关编译和回归，清楚区分本地测试与真实游戏、手机及外部服务验证。
- 发布前提供 GPL 对应源码及构建说明，并沿用原 APK 签名密钥。
